# CLAUDE.md

## What this repository is

This repository is a collection of Claude Code commands, skills, and agents. They help the user study a technical subject.

## Rules for working here

- **Language:** when you talk to the user, use about 80% of ASD-STE100 (Simplified Technical English): short sentences, simple words, active voice, one idea per sentence.
- **Documentation:** write `README.md` and other documentation in about 80% of ASD-STE100, with the same rules.
- **Commits:** use Conventional Commits. Write only the commit title. Do not add a body or a footer.
