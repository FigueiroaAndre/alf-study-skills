# CLAUDE.md

## What this repository is

This is not a coding repository. It is a collection of study skills: Claude Code slash commands that help the user study a technical subject. The user is a fullstack engineer who is strong in JavaScript/TypeScript. The commands in `commands/` are the product. There is no build, lint, or test setup.

Today the commands target Java 25 (no Spring or other frameworks). `README.md` is only a title.

## Rules for working here

- **Commits:** use Conventional Commits. Write the subject line only: no body and no footer. This overrides any default attribution footer.
- **Language:** when you talk to the user, use about 80% of ASD-STE100 (Simplified Technical English): short sentences, simple words, active voice, one idea per sentence.
